# Requisitos Funcionais

## RF-01 — Consultar Eventos Disponíveis

**Descrição:**  
O sistema deverá permitir que participantes consultem os eventos disponíveis, incluindo suas informações relevantes para inscrição.

**Rastreabilidade:**
- Contexto: CTX-01, CTX-03
- Ambiguidade/Ponto de esclarecimento: —
- Stakeholder: Participante

---

## RF-02 — Realizar Inscrição em Eventos

**Descrição:**  
O sistema deverá permitir que participantes realizem inscrições em eventos disponíveis, respeitando as regras de vagas, pagamento e demais condições definidas para o evento.

**Rastreabilidade:**
- Contexto: CTX-03, CTX-05, CTX-07
- Ambiguidade/Ponto de esclarecimento: AIC-02
- Stakeholder: Participante

---

## RF-03 — Inscrever-se em Workshops

**Descrição:**  
O sistema deverá permitir que participantes realizem inscrições em diferentes workshops vinculados a um evento.

**Rastreabilidade:**
- Contexto: CTX-03, CTX-07
- Ambiguidade/Ponto de esclarecimento: AIC-03
- Stakeholder: Participante

---

## RF-04 — Controlar Disponibilidade de Vagas

**Descrição:**  
O sistema deverá controlar a quantidade de vagas disponíveis para cada evento ou atividade, impedindo que a quantidade de inscrições ultrapasse a capacidade definida.

**Rastreabilidade:**
- Contexto: CTX-04, CTX-07
- Ambiguidade/Ponto de esclarecimento: AIC-02
- Stakeholder: Organizador

---

## RF-05 — Acompanhar Inscrições

**Rastreabilidade:**
- Contexto: CTX-03
- Ambiguidade/Ponto de esclarecimento: —

## RF-06 — Emitir Comprovante de Inscrição

**Rastreabilidade:**
- Contexto: CTX-03

## RF-07 — Cancelar Inscrição

**Descrição:**  
O sistema deverá permitir o cancelamento de inscrições para os eventos que disponibilizarem essa possibilidade.

**Rastreabilidade:**
- Contexto: CTX-03, CTX-07
- Ambiguidade/Ponto de esclarecimento: AIC-01
- Stakeholder: Participante / Organizador

---

## RF-08 — Gerenciar Lista de Espera

**Descrição:**  
O sistema deverá permitir o gerenciamento de uma lista de espera para eventos ou atividades que atingirem sua capacidade máxima, conforme as regras definidas.

**Rastreabilidade:**
- Contexto: CTX-04, CTX-07
- Ambiguidade/Ponto de esclarecimento: AIC-02
- Stakeholder: Participante / Organizador

- Ambiguidade/Ponto de esclarecimento: —
